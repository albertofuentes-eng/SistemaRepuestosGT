# Objetivo

Desarrollar un sistema web para administrar un negocio de venta de repuestos de motocicletas, carros y tuc tuc.

El sistema permitirá controlar inventario, compras, ventas, clientes, proveedores y reportes desde una interfaz sencilla y segura.

---

# Tipo de negocio

Pequeño negocio.

Promedio de ventas:

5 a 10 ventas diarias.

---
