# SistemaRepuestosGT

## Descripción

Sistema web para la administración de un negocio dedicado a la venta de repuestos para motocicletas, carros y tuc tuc.

El sistema permitirá controlar productos, inventario, compras, ventas, clientes, proveedores y reportes, ofreciendo una solución sencilla, rápida y segura para pequeños negocios.

## Tecnologías

- ASP.NET Core MVC (.NET 8)
- C#
- SQL Server
- Entity Framework Core
- Bootstrap 5
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
